# M4 persistence correction — 2026-11-26

## Lesson and adoption

The initial M4 attempt found useful countermodels and source gaps, then ended
after its self-selected sequence of three avoidance and two recovery candidates.
The user had requested sustained effort on a hard open problem. Treating those
small bounds as the endpoint was an agent decision, not a demonstrated external
blocker. The earlier retrospective's conclusion that no process correction was
needed is superseded by this user feedback; the mathematical findings stand.

The instructions mixed “do not give up” with permission to hand back an
obstruction when recovery produced no next step. The restart wording required
a new estimate before research could resume. That made discovery a prerequisite
for doing the work intended to produce it.

Adopted in [AGENTS.md](../../AGENTS.md), the
[meta-plan](../meta-proof-plan.md#persistence-and-stopping-conditions), workflow
and current M4 prompt: bounds govern experiments; the authorized objective
continues. Reassess, change the question or method, and perform the next bounded
investigation. When no proof candidate is available, generate questions tied to
the obstruction and test what they could teach. Stop a refuted route while
retaining the objective, exact theorem and all proof standards.

Real interruptions retain their cause and a concrete continuation question.
Handoffs and entry pointers restore that context without treating historical
stopping proposals as current instructions. User/host limits, permissions,
review recovery limits and scope exclusions still apply. No new tool, global
memory, runtime mechanism or dependency is introduced.

## Evaluation and limits

The smallest credible correction is consistent repository instructions, not a
new orchestration system. Manual scenario checks cover failed candidates, no
surviving idea, an exhausted local quota, a required review failure, an explicit
user stop, a binding resource limit, and context resumption. The
[review report](../agy-reports/m4-persistence-review.md) owns validation and
independent-review evidence.

This is a process correction, not mathematical progress or evidence of improved
discovery rates. Its behavioral effect remains unmeasured. In continued M4
research, evaluate whether an unsuccessful cycle is followed by a materially
different inquiry without repeated user prompting, and whether the result
changes understanding. Repeated activity without learning is a reason to revise
the method, not evidence of perseverance. No instruction guarantees a proof.
